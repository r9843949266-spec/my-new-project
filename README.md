# Painting with AI

Building AI course project


## Summary
My New Project is an AI-powered application designed to demonstrate practical AI concepts learned during the Building AI course. 
It includes features such as Painting with AI. 
The project is built using Python and relevant AI libraries, aiming to provide a hands-on experience in AI development and problem-solving.


## Background
Many people want to create art but lack technical drawing skills. AI can support creativity by generating visual content quickly and intuitively, making digital art more accessible.

## How is it used?
Users provide a text description or simple sketch, and the AI generates a painting-style image. This can be used for learning, creative projects, or inspiration.
